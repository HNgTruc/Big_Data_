# experiments — thí nghiệm hiệu năng

Mỗi thí nghiệm một thư mục con có README và `run.py` (tạo bằng skill `/new-experiment`). Agent phụ trách: `benchmark-analyst`.

Kết quả ghi vào `results/`. Danh sách thí nghiệm dự kiến (chưa chạy): mở rộng theo dữ liệu, mở rộng theo worker, CSV so với Parquet, shuffle so với broadcast join, skew, cache.

- Trạng thái: chưa có thí nghiệm nào.

# docs — tài liệu của đồ án

| Thư mục | Nội dung |
|---|---|
| `requirements/` | Tóm tắt file yêu cầu đồ án (nguồn chuẩn để đối chiếu) |
| `design/` | Schema dữ liệu và tài liệu thiết kế |
| `references/` | Danh mục slide, sách và tài liệu tham khảo, kèm nơi lưu |

Tài liệu gốc (docx, pdf, slide) nằm trên Google Drive của người dùng; ở đây chỉ lưu bản tóm tắt có chỉ rõ nguồn.
